# 42 Piscine 

This repository contains my personal implementations of the exercises and projects completed from the 42 Piscine bootcamp.

---

## Overview

The 42 Piscine is an intensive foundational program focused on low-level C programming, Unix environments, and memory management. All solutions are written from scratch without relying on external libraries, adhering strictly to 42's coding standard (The Norme).
